1. One-Click Launch Files (GitHub ZIP Usage)

Operating System File to Double-Click / Run What It Does Automatically
Windows 10 / 11 Launch_AgriNexus.bat Verifies Node.js, creates .env from .env.example, runs npm install if node_modules is missing, launches server, opens http://localhost:3000.
macOS Launch_AgriNexus.command Installs missing packages, boots Express + Vite server on port 3000, opens default browser. (If macOS blocks first launch, right-click → Open).
Linux / Git Bash ./start-agrinexus.sh Installs dependencies if missing, starts backend + UI on port 3000, opens browser via xdg-open.

Prerequisite: Install Node.js v20 LTS or v22 from https://nodejs.org/ before double-clicking any launcher.

Environment Variables (.env)

  • GEMINI_API_KEY — Required for live AgriNexus Assist RAG chat powered by Gemini. Without it, the app still boots cleanly and supports offline deterministic agronomy templates.
  • SESSION_SECRET — Secret key used to sign persistent HMAC-SHA256 Bearer tokens (recommended for production deployments).
  • PORT — Server listening port (defaults to 3000).

3. Authentication Flows & Security Controls

  1. Mobile + 6-Digit OTP Flow (Primary for Farmers):
    • POST /api/auth/request-otp normalizes the 10-digit Indian mobile number and stores a single-use OTP expiring in 300 seconds.
    • POST /api/auth/verify-otp verifies the OTP, marks it as used (cannot be reused), checks farmer FPO approval status, resets failed attempts, and issues a signed Bearer session token.
  2. Email + Password Flow (FPO Admin, Buyer, System Admin, Farmers):
    • POST /api/auth/login verifies password hashes via crypto.scryptSync + crypto.timingSafeEqual.
  3. New Account Registration:
    • POST /api/auth/register supports registering as farmer (10-digit mobile + optional OTP), fpo_admin, or buyer (email + min 6-character password).
  4. Account Recovery (Forgot / OTP Recovery):
    • POST /api/auth/recover verifies a 6-digit OTP for a registered mobile number, clears any active lockout, optionally resets password, and logs the user back in.
  5. Brute-Force Lockout Policy:
    • 5 consecutive failed login/OTP attempts automatically lock the account for 15 minutes (HTTP 423 Locked).
    • FPO Admins and System Admins can also unlock accounts manually from the Admin Console.
  6. Persistent Signed Sessions & Offline Sync Recovery:
    • Sessions issue HMAC-SHA256 signed tokens (<userId>.<issuedAt>.<hmac>) stored in browser localStorage under agrinexus_token alongside agrinexus_user.
    • Signed tokens survive server restarts, allowing queued offline batches (agrinexus_offline_batches) to sync cleanly on reconnect. If a token is missing or invalid (HTTP 401), the client automatically clears cached session state and returns cleanly to the login screen.

5. Production Deployment Commands & Checklist

npm install
npm run build
NODE_ENV=production node server.ts
  • Data Persistence: Local runs store state in data/agrinexus-db.json (with automatic fallback to /tmp/agrinexus-data/agrinexus-db.json in read-only containers). For multi-instance cloud scaling, migrate server/store.ts to PostgreSQL (Cloud SQL) or Firebase Firestore.
  • External Production Integrations: Connect MSG91/Twilio in /api/auth/request-otp (and remove devPreviewCode), Agmarknet Data.gov.in API in /api/market-prices/refresh, and OpenWeatherMap API in batch creation.
